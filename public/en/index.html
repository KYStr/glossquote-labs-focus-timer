How timing works

The timer uses your device clock. The display may update late while this tab is in the background or your device is asleep; it recalculates when you return. Moving the clock forward can end a session early.

There are no sounds or system notifications. Reloading this page or switching languages clears the timer, so keep this page open while you work.

Start a focus session

  1. Enter a whole number from 1 to 180, such as 25 minutes for reading.
  2. Select “Start timer.” Pause at any time to keep the remaining time.
  3. Select “Resume” when you are ready, or “Cancel timer” to return to the set duration.

When the timer ends, it stays at 00:00. Start again or set a new duration when you are ready.

Frequently asked questions

Will I get an alert if I close the page?

No. This timer has no sound or system notifications. Reloading the page, switching languages, or reopening a reloaded page clears the timer.

Does it stop when I switch tabs?

The deadline stays in place, but the background display may stop updating. When you return, the timer recalculates the remaining time from your device clock. Sleep can also delay updates. If your browser discards and reloads the page, the timer returns to its initial 25 minutes.

Will it start a break automatically?

No. Each session is one timer. You choose when to start another.

What if I change the device clock?

If the clock moves backward, the timer pauses. Check the clock before resuming the remaining time. Moving it forward can end the timer early.

Does it save my focus history?

No. There is no account or history; timer state stays in this page's memory. The tool does not upload your timer data. The hosting service still receives ordinary connection information when page assets load.
